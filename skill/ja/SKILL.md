# misread-lexicon — 同じ語で二度誤読させない

誤読は不服従でもルール不足でもない。**指示は在って、その中の語ひとつが別のものに解決された**だけ。書き手には
意図どおりの文が見え、読み手には筋の通った文が見えるので、**両方から見えない**。何も落ちないまま作業が別の
方向へ行き、同じ語が何度でも同じことをする。

誤読は**形で再発する**。だから登録できる。

## 6つの型

| 型 | 機序 | 所管 |
|---|---|---|
| M1 | 短い多義トークン: 2〜3文字の略語が日常語と衝突し「誤字」と読み替えられる | 本linter |
| M2 | 非ASCII識別子が符号化・パイプ境界で化け、**壊れた写しの方**を実体として診断する | 符号化ガード |
| M3 | 語彙乖離: docは書き手の語彙、読み手は自分の語彙で検索、空振りを不在と読む | **無し＝手の規律** |
| M4 | 記号の構文衝突: テキストでは正しく、描画すると別の意味（テーブル内の生パイプ） | markdown linter |
| M5 | 相対参照: `昨日`・`上`——後から読まれた時点で参照先が無い | 本linter |
| M6 | 片側列挙の判定語: 含まれるものだけ列挙し否定側を閉じず、読み手が対象外を発明する | **手監査** |

## 誤読を踏んだらこうする

1. **型を名指す**（上表）。M1かM5なら登録可能＝次回は機械が捕まえる。
2. **台帳に1行足す**。変更はそれだけ（linterが実行時にテーブルを読むのでコード編集不要）:
   `| M1 | UE | UE(Unreal Engine)（ファイル内初出時） | 2026-08-28 |`
3. **元を直す。ただし直す対象を間違えない**:
   - M1 → そのファイルの初出で展開する。特に **skillの `description:`** に注意——毎セッション振り分けに
     読まれるので、ここの誤読は委譲先を狂わせる。
   - M5 → 絶対日付へ置換。**ただし引用や概念的用法なら、語でなくスコープが誤り**（下記）。
   - M6 → **例を増やさない。** 該当例はたいてい既に在って読み飛ばされている。否定側を閉じる:
     `——それ以外は全て該当`。
4. **走査して0を確認**: `python tools/check_misread_words.py`

## 引用をlinterに直させない

検出器が鳴った時の最初の問いは「検査器を満たすようにどう書き直すか」ではなく、
**「このファイルはそもそもスコープ内だったか」**。

実測例: M5が個人的なノートの `明日` に発火した。そこでは概念として使われ、一部は本人発言の逐語引用だった。
腐っているものは何も無い。書き換えていたら、検査器を満たすために意味を壊していた。正しい処方は**既定スコープを
絞り、その行を負対照テストへ焼く**ことだった。

**効くのは語でなくスコープ**。M1は指示文書に（誤読が作業の宛先を狂わせる場所）、M5は自分の規約が既に絶対日付を
要求している場所（引き継ぎ文書）にだけ効かせる。

## M2・M3・M4・M6に検出器を足さない

- M2/M4には既に所管がある。同じ領域に2つ目を置くと、食い違う判定が2つできてどちらも信用されなくなる。
- M3は原理的に不能: 検出とは「誰も書かなかった同義語の**不在**」の検出。実測で**最多**の型であり、だからこそ
  自動化を騙るのが一番害がある。代わりに規律を持つ——**「その機能は無い」と言う前に、在るならそこに書かれて
  いるはずのファイルを開く**。空振りした検索が証明するのは自分の語彙が一致しなかったことだけ。
- M6の実出現は約12件。12件のための検出器は、使うより調整に時間がかかる。

正常な状態に鳴る検査器は、無視される訓練を与え、その時点で何も守らなくなる。

## 過去の誤読を回収する

`python tools/mine_misreads.py --out candidates.jsonl` が既存トランスクリプトを読み、**既に起きた訂正**を
その直前にエージェントが読んでいたものと一緒に出す。2段（読み違いを明示した発話／一般的な訂正）・英日両対応。
**ゲートでなくレポート**なので常にexit 0——どれが本物かは人が決める。

歩留まりは低い: 参照コーパスでは発話1220件から生の一致51件、大半は機械生成の会話要約で除外が必要だった。

## ファイル

- `lexicon/lexicon.ja.md`・`lexicon/lexicon.en.md` — linterが読む台帳（マーカーで位置特定・列は位置で決定・
  何語でも可）
- `tools/check_misread_words.py` — 検出のみ・書き換えなし・検出ありでexit 1
- `tools/mine_misreads.py` — 過去ログ採掘器・常にexit 0
- `misread-lexicon.json` — 自分のパスと走査スコープ
